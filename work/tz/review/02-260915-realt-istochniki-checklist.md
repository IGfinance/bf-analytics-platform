# ТЗ 02 Реальт — ручной чек-лист проверки загрузки источников

**Дата:** 2026-09-15. Для каждого источника проекта Реальт (project_id=2, БД
`realt`): как запустить загрузку и как убедиться, что данные легли. Страница
загрузки: `https://report.finance-black.ru/cloudsix/p/realt/upload`.

Проверка в ClickHouse (на сервере): `set -a; . /var/www/report.finance-black.ru/.env; set +a`,
затем `clickhouse-client --database realt --password "$CLICKHOUSE_PASSWORD" -q "<SQL>"`.

Общие инварианты для всех источников:
- Битый файл / разрыв сети до ClickHouse → страница НЕ падает, показывает
  понятную ошибку (не 500-трейс).
- Повторная загрузка не двоит: у всех таблиц `ReplacingMergeTree` со своим
  ключом дедупа — перезаливка обновляет, а не добавляет.
- Все строки пишутся с `project_id = 2`.

---

## 1. Банковская выписка 1С (`bank_1c` → `bank_statements`)
1. На странице загрузки карточка «Банковская выписка 1С», выбрать один или
   несколько `.txt` файлов выписки → «Загрузить».
2. Ожидаемо: страница результата «Загружено файлов: N, строк: M».
3. Проверка: `SELECT count(), min(operation_date), max(operation_date) FROM bank_statements WHERE project_id=2`.
4. Негатив: загрузить не-`.txt` → «Ни одного .txt файла не найдено» (форма, не 500).

## 2. Карточная выписка PDF (`card_pdf` → `card_statements`)
1. Карточка «Карточная выписка PDF», выбрать `.pdf` справку(и) → «Загрузить».
2. Результат: число файлов/строк; в блоке «Держатели карт» — ожидаемые ФИО.
3. Проверка: `SELECT count(), uniqExact(cardholder) FROM card_statements WHERE project_id=2`.
4. Негатив: битый/непарсящийся PDF → понятная ошибка на странице результата.

## 3. Выгрузка Клиентикс (`klientiks` → `klientiks_operations`)
1. Карточка «Выгрузка Клиентикс», выбрать `.csv` (cp1251, `;`) → «Загрузить».
2. Результат: строк загружено + «пропущено нечитаемых строк» (неполная
   структура — норма, не теряется тихо).
3. Проверка: `SELECT count(), uniqExact(card_number), min(visit_start), max(visit_start) FROM klientiks_operations WHERE project_id=2`.
4. Спот-чек метрик: `SELECT * FROM realt_metrics_by_month ORDER BY month DESC LIMIT 3`
   — выручка/визиты/клиенты за последние месяцы вменяемы.

## 4. Google-Таблица «Зарплаты» (`gsheets_payroll` → `realt_payroll`) — pull-триггер
1. Карточка «Google-Таблица «Зарплаты»», **без файла** — кнопка «Загрузить из
   Google-Таблицы». Тянет вкладку «Импорт ФОТ» через Google Sheets API.
2. Результат: «Загружено строк: N» (пропущены строки не-ФОТ — заголовки/итоги).
3. Проверка: `SELECT count(), uniqExact(role), min(period), max(period) FROM realt_payroll WHERE project_id=2`
   (роли: Психиатры/Психологи/Администраторы/Управление/Маркетинг/Шмилович).
4. Негатив: нет доступа сервис-аккаунта к таблице / пустая вкладка → понятная
   ошибка на странице результата (форма не падает).

## 5. Google-Таблица «Расходы по статьям» (`gsheets_expenses` → `realt_expenses`) — pull-триггер
1. Карточка «Google-Таблица «Расходы по статьям»», кнопка «Загрузить из
   Google-Таблицы». Тянет вкладку «Остальные расходы».
2. Результат: «Загружено строк: N» (пропущены ячейки-статьи без суммы «-»/пусто).
3. Проверка: `SELECT count(), uniqExact(period), sum(is_shaa) FROM realt_expenses WHERE project_id=2`
   (ожидаемо ~556 строк, 22 месяца, ~76 ШАА на 2026-09-15).
4. Спот-чек: `SELECT toDate(month), expense_type, round(amount), round(amount_ex_shaa) FROM realt_expenses_by_month ORDER BY month DESC LIMIT 8`
   — расходы по типам, `amount_ex_shaa` пуст для чисто-ШАА типов.

## Metabase (после загрузок)
Коллекция «Реальт» (id 8), data source «ClickHouse Realt» (id 3 → БД `realt`):
- Модель «Реальт метрики по месяцам» (id 98) — выручка/визиты/клиенты/ФОТ.
- Модель «Реальт выручка по услугам» (id 99).
- Модель «Реальт расходы по типам» (id 100) — с колонками «с/без Шмиловича».
Открыть каждую → данные подтягиваются, колонки с русскими подписями.
