# Детальный адаптер — модели, сводные таблицы, дашборды (Metabase, коллекция «CloudSix | Админка», id 11)

Создано 2026-10-04. Данные — вьюхи `detail_adapter_*` (`src/schema_detail_adapter_views.sql`, генератор
`scripts/gen_detail_adapter_views.py`).

## Модели (native SQL, тонкая обёртка с русскими названиями колонок)

| Модель | id | Вьюха |
|---|---|---|
| Модель - Детальный адаптер WB API | 229 | `detail_adapter_wb_api` (+ `WHERE month >= '2026-01'`, как Модель 49) |
| Модель - Детальный адаптер WB xlsx | 230 | `detail_adapter_wb` |
| Модель - Детальный адаптер Ozon API | 231 | `detail_adapter_ozon_api` |
| Модель - Детальный адаптер Ozon xlsx | 232 | `detail_adapter_ozon` |

```sql
SELECT cabinet AS "Кабинет", brand AS "Бренд", month AS "Месяц", blk AS "Блок",
       grp AS "Группа", art AS "Статья", amount AS "Сумма"
FROM detail_adapter_wb_api   -- или другая вьюха
```

## Сводные таблицы (конструктор над моделью; pivot из native SQL Metabase не умеет)

Строки: Кабинет → Бренд → Блок → Группа → Статья (сворачиваются/раскрываются), столбцы: Месяц, значение: сумма «Сумма».
Общий итог по всем блокам выключен (`pivot.show_column_totals = false`): блоки 2–7 справочные и с блоком
«1 Начисления» не складываются. Итог справа по месяцам включён.

| Сводная | id | Модель |
|---|---|---|
| Сводная - Детальный адаптер WB API | 233 | 229 |
| Сводная - Детальный адаптер WB xlsx | 234 | 230 |
| Сводная - Детальный адаптер Ozon API | 235 | 231 |
| Сводная - Детальный адаптер Ozon xlsx | 236 | 232 |

## Дашборды

- 04 Дашборд - CloudSix - Детальный адаптер API — id 20 (233, 235)
- 05 Дашборд - CloudSix - Детальный адаптер xlsx — id 21 (234, 236)

Фильтры «Кабинет» и «Бренд» (`string/=`) привязаны к полям модели через dimension-target (над конструктором,
а не над native SQL, поэтому фильтрация работает).

## Сверка (проверено 2026-10-04)

Блок «1 Начисления» по каждому (кабинет, бренд, месяц) равен колонке «15 К перечислению» адаптерных карточек
43 (WB API), 204 (WB xlsx), 203 (Ozon API), 64 (Ozon xlsx) — расхождение ≤ 2·10⁻⁶; суммы листьев групп WB
равны каноническим метрикам бренд-вьюх.
