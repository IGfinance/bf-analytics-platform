# Формулы метрик — LaTeX

Один документ на проект (клиента) — единое место, где видно, как считается
каждая метрика на дашбордах Metabase, плюс ER-схема таблиц-источников.
Источник правды остаётся в коде (`src/schema_*.sql`,
`src/metabase_queries/*.sql`) — эти файлы описывают его человеческим
языком и не должны разойтись (см. последний раздел каждого документа).

- `realt.tex` — Реальт (клиника). Готово.
- CloudSix (WB + Ozon) — следующим шагом, отдельный файл `cloudsix.tex`.

## Как собрать

Локально: `pdflatex realt.tex && pdflatex realt.tex` (дважды — для
оглавления и перекрёстных ссылок), либо `latexmk -pdf realt.tex`.

Без локального LaTeX — проще всего через [Overleaf](https://overleaf.com):
создать пустой проект, загрузить `.tex`-файл, собрать (движок pdfLaTeX,
он же по умолчанию).

Документы написаны и статически проверены (баланс скобок, `\begin`/`\end`,
`\label`/`\ref`) без доступа к LaTeX-компилятору — при первой сборке стоит
проверить глазами, в первую очередь ER-диаграмму (TikZ, самая сложная по
вёрстке часть).
